# Редактор перевода Slow Damage v0.1.0

Распакуйте архив целиком и запустите **START_EDITOR.cmd**. Нужен Python 3.10
или новее; дополнительные библиотеки не требуются. Редактор откроется в браузере
по адресу http://127.0.0.1:8775/ и работает без подключения к интернету.
Если порт занят, закройте прежний редактор или запустите
`python server.py translations/translation.jsonl --port 8776`.

Каталог включает 33 830 записей: сценарий, проверенные начальные сцены и
дополнительные строки интерфейса. Есть поиск, выбор сцены, статусы проверки,
соседние реплики и оценка переносов по ширине игрового шрифта.

Измените русский текст и нажмите **Сохранить** / **Ctrl+S**. При переходе
к следующей записи редактор сохраняет изменения автоматически. Если сохранение
не удалось, переход отменяется, а набранный текст остаётся в поле.
**Alt+← / Alt+→** переключают записи. Последняя запись запоминается в браузере.

Команды озвучки в начале реплики скрыты и сохраняются автоматически.
Теги внутри текста (`<K>`, выделение, переменные) оставляйте на месте.
Редактор не позволит сохранить текст с удалёнными служебными командами.
При первом сохранении в каждом сеансе создаётся копия исходного каталога
в `translations/backups/`. Закрывать окно терминала можно после сохранения.

Результат работы — **translations/translation.jsonl**. Передайте этот файл
сборщику перевода. Правки появятся в игре после пересборки патча; редактор сам
не устанавливает изменения. Каталог не требует повторного машинного перевода.

Для работы из Git-репозитория скопируйте каталог из ZIP редактора в
`editor/translations/translation.jsonl`. Для выпуска обновлённого русификатора
нужно пересобрать игровые скрипты в сборочном окружении проекта; этот репозиторий
содержит исходники редактора и установщика. Если редактируете для автора патча,
достаточно передать ему изменённый `translation.jsonl`.
